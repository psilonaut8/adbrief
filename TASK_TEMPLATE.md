# Tool Task Template

## Goal

What should change in AdBrief?

## Inspect First

- `AGENTS.md`
- `README.md` if present
- Relevant backend, frontend, parser, storage, or AI brief files

## Rules

- Preserve existing architecture and deployment notes.
- Do not add dependencies unless necessary.
- Do not refactor unrelated files.
- No em dashes in user-facing copy.

## Acceptance

- Main workflow still works.
- Relevant route, parser, UI, or generation path is smoke-tested.
- Files changed, checks run, risks, and assumptions are reported.
