Connect your Meta Ads account

Follow the steps below — takes about 5 minutes and you only need to do this once.

1
Create a System User in Meta Business Manager
  1. Go to business.facebook.com/settings and click Settings in the left sidebar
  2. Navigate to Users → System Users → click Add → name it "AdBrief" → role: Analyst
  3. Click Add Assets → Ad Accounts → find your account → enable Analyst access → Save
  4. Now go to Accounts → Apps in the left menu → click Add → Connect an app ID → paste your App ID (from developers.facebook.com/apps) → Add.
    Don't have an app yet? Create one at developers.facebook.com → My Apps → Create App → Business type.
  5. Go back to Users → System Users → AdBrief → click Add Assets → Apps → tick the app you just added → give it Full control → Save
  6. Click Generate token → select your app from the dropdown → tick ads_read → Generate
  7. Copy the token — it only shows once
Common gotcha: Meta requires a Meta App to be linked to your System User before it can generate a token. Steps 4–5 above cover this — don't skip them or the Generate token button will be greyed out.

Your Ad Account ID looks like act_123456789. Find it under Accounts → Ad Accounts, or in the Ads Manager URL bar.
